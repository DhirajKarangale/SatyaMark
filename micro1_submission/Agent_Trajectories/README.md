# Agent Trajectories

To fulfill the Hackathon requirement for "Agent Trajectories", you must include the explicit JSON traces generated by SatyaMark's internal `tracer.js`.

### What you need to do:
1. Run your complete SatyaMark stack locally (Ensure `ENABLE_TRACE=true` is set in your `Backend/.env`).
2. Go to the DemoMedia frontend and trigger 3 diverse verification jobs:
   - **Case 1:** A complex, multi-sentence factual claim that requires decomposition and web search.
   - **Case 2:** A subjective opinion (to demonstrate the LangGraph early-exit/short-circuit logic).
   - **Case 3:** A deepfake image (if you have the forensic keys active) or another complex text claim.
3. Once completed, go to your root `traces/` folder.
4. Copy the newly generated `trace_satyamark_<jobId>.json` files and paste them into this folder (`micro1_submission/Agent_Trajectories/`).

These files serve as undeniable proof to the judges that your agent dynamically utilizes tools, handles state, and processes reasoning steps, maximizing your "Agent Solution" score.
